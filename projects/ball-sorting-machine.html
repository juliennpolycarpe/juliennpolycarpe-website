Light-Reflectance Ball Sorter

A machine that automatically sorts balls of different colors by reading how much light each one reflects. A photoresistor (LDR) positioned above the sort point measures reflected light intensity as each ball passes underneath — darker colors reflect less light, lighter colors reflect more — and the readings are used to classify and route each ball to its own bin.

  • Used a photoresistor (LDR) as a reflectance sensor to distinguish balls by color based on measured light intensity
  • Calibrated threshold values in firmware to reliably separate each color under consistent lighting
  • Drove servo motors to physically route each ball to its corresponding bin after classification

Arduino IDE · Photoresistor (LDR) · Servo Motors · Breadboard
