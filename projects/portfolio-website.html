Portfolio Website

The site you're on right now. A multi-page static site built from scratch to showcase coursework, projects, and experience, with an oscilloscope-inspired dark theme suited to an ECE/CS portfolio. Structured as a real index/detail hierarchy rather than a single scrolling page — an experience or project index links out to its own dedicated page, and coursework is organized by department with filterable category tabs.

  • Built a shared, collapsible sidebar navigation (with icon-only collapsed state) injected across every page from a single JavaScript module, avoiding markup duplication
  • Designed a distinct visual identity — Space Grotesk and JetBrains Mono typography, an amber/teal accent palette, and an animated oscilloscope trace as the signature hero element
  • Deployed as a static site through GitHub Pages, version-controlled with Git/GitHub
